# Reports

Esta pasta recebe artefatos produzidos pelas rotinas analíticas do projeto.

## EDA

Execute:

```bash
python python/eda_analysis.py
```

A saída padrão será criada em `reports/eda/`, contendo:

- resumo em Markdown;
- tabelas agregadas em CSV;
- gráficos em PNG.

Os artefatos são derivados dos dados sintéticos e podem ser regenerados a qualquer momento.
